Only fields listed in the Relevant Fields section and marked keep in donation are included in the donated data. Optionally, you can provide a field alias via rename to, which is used both in the data export and when referencing the field in Extraction Rules. Data is then extracted and transformed according to the defined Extraction Rules (if any).

Extraction Rules are applied row-by-row to the data located at the defined Extraction Root, in the order you define them. All extraction happens on the participant's device, using JavaScript.

Configuring extraction:

  1. In the Extraction Fields section, list each field you want to keep and mark it keep in donation.
  2. Add Extraction Rules to filter (delete rows) or transform values using comparison or regex operators.
