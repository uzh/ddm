# Configuration

These guides cover common ways to adapt DDM to your institution after
[installation](../installation.md):

- [User Authentication](user_authentication.md): Let researchers log in with
  their institutional account through OpenID Connect (OIDC).
- [Template Customization](customize_templates.md): Override DDM's
  templates to change the look of the researcher interface.
- [CKEditor Configuration](customize_ckeditor_configs.md): Change the editor
  toolbar that researchers use for instructions and question texts.

For a complete list of available settings, see
[Settings Reference](../settings_reference.md).
