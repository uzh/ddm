# Reporting issues and getting help

If you encounter issues or detect a bug, please open a new issue in the
[GitHub repository](https://github.com/uzh/ddm).

If you need help navigating the application, please first look for a solution in the sections of
this documentation. If you are stuck and don't find what you are looking for, feel free to
contact us at [datadonation@ikmz.uzh.ch](mailto:datadonation@ikmz.uzh.ch).
