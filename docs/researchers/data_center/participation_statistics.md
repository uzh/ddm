# Participation Statistics

The Participation Statistics currently display the following information. Test runs made
through the project's [Test Link](../test_and_launch.md) are excluded from all of these:

- _At least one donated file_: The number of participants who successfully donated at
  least one file.
- _Donated Files_: The number of successfully donated files. A "status by blueprint" link
  opens a breakdown of donation outcomes per Blueprint.
- _Started_: The number of participants that started the study.
- _Completed_: The number of participants that reached the debriefing page of the study.
- _Completion Rate_: The number of completed divided by the number of started participations.
- _Avg. Time to Complete_: The average time it took completed participants to go from
  starting the study to reaching the debriefing page.
